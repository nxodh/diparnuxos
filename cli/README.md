# cli (명령행 도구)

- 확인 날짜: 2026-10-10
- 상태: 초안. 구현은 Phase 2 예정이다.

- **책임(초안)**: 터미널에서 `lightlixd`의 상태를 확인하고 기본 조작을 하는 명령행 도구다.
- **범위**: 구체적인 명령 목록은 아직 정하지 않았다. 데몬 기능이 정해진 뒤에 명령을 정한다.
- **언어와 배포 형식**: 정하지 않았다. Phase 2에서 결정한다.
- **의존**: `lightlixd`가 제공하는 인터페이스에 의존한다. 데몬 쪽 인터페이스를 먼저 정한다([daemon/README.md](../daemon/README.md)).
- **라이선스와 모델 표시**: 모델을 내려받는 명령을 두면 모델 라이선스를 함께 보여 준다. 방침은 [docs/licenses.md](../docs/licenses.md) 7절에 있다(초안).
- **구현 Phase**: 2.

열린 문제: 명령 목록, 언어, 데몬과의 통신 방식.
